# Git by Bit Practice

A small HTML and CSS repository used to practice Git commits and reverting changes.

## View the page

```sh
git clone https://github.com/PravatKumaraMishra/gitByBitRepo.git
cd gitByBitRepo
```

Open `hello.html` in a browser. No packages, build step, or server are required. The page displays “Hello, World!” and loads `style.css`.

## Files

- `hello.html`: HTML document and stylesheet reference.
- `style.css`: page styles.

## Learning history

The commits include editing the page, adding the HTML5 doctype, introducing a bug, and reverting it. Use `git log --oneline` and `git show <commit>` to inspect those steps. This is a Git exercise, not a full website.
